# Personel Yönetim Sistemi

Python, Flask ve SQLite kullanılarak geliştirilmiş basit bir Personel Yönetim Sistemi.

## Özellikler

- Kullanıcı girişi ve çıkış
- Personel ekleme
- Personel listeleme
- Personel arama
- Personel düzenleme
- Personel silme
- SQLite veritabanı kullanımı

## Kullanılan Teknolojiler

- Python
- Flask
- SQLite
- HTML
- CSS
- Jinja2

## Kurulum

Terminalde:

```bash
pip install -r requirements.txt
python app.py
